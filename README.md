# دعوة شنودة وليزا

## الملفات
- `index.html` — الدعوة (الغلاف، وبعد "افتح الدعوة" الصفحة الداخلية والموسيقى)
- `admin.html` — لوحة التحكم (الصور، الأماكن، الميعاد، الموسيقى، التهاني)
- `config.js` و `common.js` — إعدادات واتصال بقاعدة البيانات، ماتعدلش فيهم
