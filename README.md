# دعوة شنودة وليزا

## الملفات
- `index.html` — الدعوة (الغلاف، وبعد "افتح الدعوة" الصفحة الداخلية والموسيقى)
- `admin.html` — لوحة التحكم (الصور، الأماكن، الميعاد، الموسيقى، التهاني)
- `config.js` و `common.js` — إعدادات واتصال بقاعدة البيانات، ماتعدلش فيهم

## الرفع على GitHub Pages
1. ادخل github.com واعمل Repository جديد، مثلاً `shenoda-liza`، وخليه Public.
2. دوس **Add file → Upload files** واسحب الأربع ملفات (من غير الفولدر)، وبعدين **Commit changes**.
3. روح **Settings → Pages**، وتحت Branch اختار `main` والفولدر `/ (root)` ودوس **Save**.
4. بعد دقيقة أو اتنين اللينك هيظهر فوق:
   - الدعوة: `https://USERNAME.github.io/shenoda-liza/`
   - لوحة التحكم: `https://USERNAME.github.io/shenoda-liza/admin.html`

## الدخول على لوحة التحكم
- الإيميل والباسورد اتبعتولك في الشات. غيّر الباسورد من تبويب "الحساب" أول مرة تدخل.
